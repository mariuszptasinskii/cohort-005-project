# Refund eligibility is judged at request time, and access is frozen while a Refund Request is open

The refund rules (fourteen-day window, watch limit, completion limit, no claimed team seat) are checked only when the learner raises a Refund Request. When the team decides, it does not check them again: a request that was eligible when raised stays valid. To stop learners from raising a request just under a limit and then carrying on with the course while it waits, the learner loses access to the course while the Refund Request is open. For a team licence, its seats can't be claimed during that time. Access comes back if the request is declined or withdrawn.

## Considered Options

- **Re-check the rules at decision time.** Rejected: a learner who keeps learning while waiting, because nothing stopped them, gets declined because of how long the review took.
- **Leave it to the team's judgement, showing progress then and now.** Rejected: whether the loophole closes depends on an admin noticing.
